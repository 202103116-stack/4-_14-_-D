# 노트북 사용 안내

1. `4주차_14조_미션D.ipynb` 파일을 Google Drive에 업로드하고 Colab으로 엽니다
   (Drive 접속 → 새로 만들기 → 파일 업로드 → 우클릭 → Google Colaboratory로 열기).
2. Colab에서 왼쪽 파일(폴더) 아이콘 → 업로드 → `../data/서울시_생활인구_202604_dl0830.csv`를 함께 업로드합니다.
   (또는 Google Drive 마운트 후 경로를 수정해도 됩니다.)
3. 우측 상단 **공유** → "링크가 있는 모든 사용자"로 권한 설정 → 링크를 복사해
   `../report/4주차_14조_팀보고서.md`의 "0. 팀 Colab 노트북 공유 링크"에 붙여넣습니다.
4. 이후 작업은 이 Colab 노트북을 "정본"으로 삼아 진행하세요. 이 폴더(VSCode)의 .ipynb는 로컬 테스트/백업용입니다.
5. 제출 직전, 팀원 3명이 각자 자신의 Google 계정으로 이 Colab 노트북에서
   **런타임 → 다시 시작 및 모두 실행**을 돌려 `../logs/재현성_확인표.md`를 채우세요.
