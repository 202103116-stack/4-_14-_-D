## 허용 / 기록 필수 / 금지 (팀과제안내 14p)
- **허용**: 정제·집계 코드 생성 요청, 에러 메시지 해석 요청, 개념 설명 요청, 보고서 문장 다듬기
- **기록 필수**: 무엇을 물었는가, 무엇을 받았는가, 어떻게 검증했는가, 채택/수정/기각
- **금지**: AI 제안을 검증 없이 채택 / AI가 만든 수치를 실행 없이 기재 / 기록 없이 AI 코드 사용
