# 4주차 팀과제 — 14조 · 미션 D (방과후 청소년 공간)

## 미션 요약 (공통 규칙①: 의사결정자·결정은 고정, 그 외는 우리 조가 채움)

| 항목 | 내용 |
|---|---|
| 의사결정자 | 청소년정책 담당자 |
| 결정할 것 | 방과후 청소년이 많이 머무는 자치구에 공간을 새로 연다 |
| 분석 범위 | 15~18시 · 10대 |

| 비중 지표 | 같은 시간대 전 연령대 합계 대비 10대 비중 (자치구별) |
| 힌트 | '생활인구'는 그 시각 그곳에 있던 사람(체류 인구)입니다. 거주 청소년(주민등록 인구)과 다른 개념인지 2주차 내용을 떠올릴 것 |
| 공통 데이터 | `서울시_생활인구_202604_dl0830.csv` — 교수님 제공, 교육용으로 오류가 의도적으로 삽입된 가공 데이터. 기준일 2026-04-15 단 하루, 실제 서울시 공식 통계 아님(보고서 '한계'에 반드시 명시) |

## 공통 규칙 (전 미션 동일)
1. 의사결정자·결정은 고정, 가설 문장의 나머지 빈칸은 조가 채운다
2. 절대 규모와 비중을 둘 다 계산하고 교차한다
3. 후보 3곳을 고르되, 근거 부족하면 '2곳 + 판단보류 1곳'도 정답
4. 같은 미션(4·9·14조)의 다른 조와 결론이 달라도 된다 — 근거가 설명되면 감점 없음

## 진행 방법 추천 (VSCode + Colab 혼합)
이 과제는 "재현성"이 핵심 배점(재실행 확인표: 팀원 3명이 각자 계정에서 처음부터 다시 돌려 숫자가 같아야 제출 가능)입니다. 로컬 VSCode만 쓰면 팀원마다 파이썬/pandas 버전이 달라 숫자가 미묘하게 어긋날 위험이 있고, 보고서에 적어야 하는 "공유 링크"도 로컬 파일은 만들 수 없습니다. 그래서 다음과 같이 역할을 나누는 걸 추천합니다.

1. **VSCode(이 폴더)** — 초안 작업·자료 정리용
   - 프롬프트 초안 작성(`logs/정제로그.md`, `00_가설_질문정의.md`), 보고서·발표 초안 작성(마크다운), 데이터 사전 점검(`docs/data_description.md` 참고)을 여기서 먼저 해보고 다듬습니다.
   - 로컬 Python/Jupyter로 코드를 미리 테스트해봐도 됩니다(검증 습관을 들이는 데 도움).
2. **Google Colab** — 제출용 "진짜" 노트북
   - `notebook/4주차_14조_미션D.ipynb`를 Colab에 업로드(파일 → 노트북 업로드) → **공유 설정(링크가 있는 모든 사용자: 댓글 가능/편집 가능)** → 그 링크를 `report/4주차_14조_팀보고서.md`에 기재.
   - VSCode에서 검증한 코드를 Colab 셀에 옮겨 붙이고, 팀원 3명이 각자 자기 Google 계정으로 "런타임 → 모두 실행"을 돌려 `logs/재현성_확인표.md`를 채웁니다.
3. 최종 제출 전 `report/`·`slides/`의 .md 파일을 각각 PDF(또는 HWP/PPTX)로 변환합니다.

이렇게 하면 VSCode의 빠른 반복 편집과 Colab의 "팀 공유·재현성 보장"을 둘 다 가져갈 수 있습니다.
